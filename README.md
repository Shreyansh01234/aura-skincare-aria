## Overview

Aura Skincare is a customer-support demo featuring **Aria**, a friendly assistant for common skincare-store questions. Start a conversation by voice or text, see the live transcript, and review a session summary.

The experience is designed to feel calm and premium: warm neutral surfaces, rose and sage accents, subtle motion, and layouts that adapt to desktop, laptop, and mobile screens.

> **Project status:** This is a front-end demo with sample order data and locally defined response rules. It is not connected to a live store, fulfilment system, or external AI service.

## Highlights

- **Voice and text chat** — speak to Aria or use the message composer.
- **Free browser speech** — uses built-in browser speech recognition and speech synthesis; no Azure key or paid speech API is needed.
- **Hindi-first conversation** — speech recognition is configured for Hindi (`hi-IN`), with Hindi assistant responses.
- **Sample order support** — try the included `ORD-101`, `ORD-102`, and `ORD-103` examples.
- **Store-policy responses** — demo responses cover delivery, returns, cancellations, and out-of-scope requests.
- **Conversation transcript and summary** — review the conversation as it happens and see a session summary.
- **Responsive, accessible interface** — compact mobile layout, clear controls, and reduced-motion support.
- **No app secrets required** — the demo runs locally without API keys or environment variables.

## Getting started

### Requirements

- Node.js 20.9 or later
- npm (included with Node.js)
- A current desktop or mobile browser

### Install and run

```bash
git clone https://github.com/Shreyansh01234/aura-skincare-aria.git
cd aura-skincare-aria
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Try the conversation

1. Select **Start a call**.
2. Allow microphone access if you want to use voice.
3. Turn on the microphone and speak in Hindi, or type a message.
4. Ask about an example order, for example: “Mera order ORD-101 kahan hai?”
5. End the call to view the session summary.

## Voice support

Voice input and spoken replies use browser-native Web Speech APIs. For the best chance of speech recognition support, use a current version of **Chrome or Edge**, open the app on `localhost` or HTTPS, and allow microphone access.

Browser support varies by device. Speech recognition may rely on the browser vendor’s online speech service, so it may require an internet connection and can be unavailable even when microphone permission is granted. Hindi voice availability also depends on installed browser and operating-system voices. If voice recognition is unavailable, use the text composer.

## Demo behavior and limitations

- Order records in `data/orders.ts` are fictional sample data for this demo.
- Assistant replies are generated by client-side rule matching; there is no connected language model.
- The API route examples are local demo handlers, not integrations with a real order-management platform.
- Do not enter real customer information or treat sample order statuses as live data.
- Speech recognition and speech synthesis are browser-dependent and are not guaranteed to work offline.
